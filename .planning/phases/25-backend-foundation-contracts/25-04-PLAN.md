readCappedJson (RESEARCH Pattern 2, minus Buffer):
- Check the content-type header first (must start with application/json, case-insensitive).
- Reject Content-Length over the cap immediately.
- Otherwise read `req.body.getReader()` chunks, summing byteLength. Cancel the reader and return 413 as soon as the total exceeds the cap.
- Concatenate into one Uint8Array, decode with `new TextDecoder('utf-8', { fatal: true })`, and JSON.parse inside try/catch.
Cap default = MAX_BODY_BYTES from @trivial-world/types (D-08).

errorResponse body must validate against ApiErrorSchema, and zodIssueSummary messages use Zod's message text only. Both matter because responses must not echo input (T-25-16).

probeDb uses Promise.race with a timer (clear the timer in finally) and measures latency with `performance.now()`.
